TaskFocus is a modern, polished task management application built with React and Vite. It is designed to showcase clean UI/UX, reusable component structure, interactive state handling, and practical frontend engineering skills in a portfolio-friendly project.

## Why this project stands out

This project demonstrates:

- A clean and professional task management experience
- Component-based React architecture
- Interactive task creation, editing, filtering, and sorting
- Persistent data storage using localStorage
- A responsive and visually appealing interface
- Strong attention to usability and user experience

These are the kinds of skills that recruiters often look for in frontend developers: thoughtful UI design, state management, user interaction flow, and product-focused development.

## Key features

- Add tasks with title, priority, category, due date, and notes
- Edit and delete tasks with a smooth in-app experience
- Mark tasks as complete or undo completion
- Filter tasks by status, priority, and category
- Search and sort tasks for better organization
- Reorder tasks with drag-and-drop
- Track progress with a visual completion summary
- Toggle between light and dark themes
- Save tasks locally so data persists after refresh

## Tech stack

- React 19
- Vite 7
- JavaScript (ES6+)
- CSS3
- ESLint for code quality

## Project structure

- src/Components: UI components such as task form, task list, and progress tracker
- src/utils: task filtering and normalization logic
- public: static assets

## Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Usage

- Create a new task from the input form
- Organize tasks using filters and sorting controls
- Use drag-and-drop to reorder your list
- Review your progress through the tracker panel
